NC Land Grants Data Scraper

This tool queries nclandgrants.com for each land grant ID found in your NC_Iredell.mbl file and saves the results as a JSON database.

Requirement: You must be signed in to nclandgrants.com in your browser for the scripts to work.

How It Works

Step 1: Open nclandgrants.com and ensure you are signed in

Step 2: TEST - Run on one grant first

Copy the test script below, open the browser console on the nclandgrants.com tab (F12 > Console), paste it, and press Enter. This tests one grant (Rowan-3090) and shows you the raw HTML structure so we can verify parsing works.

After running, check the console output. It will show the raw HTML of the search results and grant detail page, plus what data was extracted.

Step 3: FULL RUN - Scrape all 126 grants

Once the test looks good, copy the full script, paste it in the console on nclandgrants.com, and press Enter. It will process all 126 grants with a 2-second delay between each.

Estimated time: ~5-8 minutes. When done, it auto-downloads nc_iredell_grants.json.
